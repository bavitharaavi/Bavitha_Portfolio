# Bavitha Raavi | Portfolio

Personal portfolio website for Bavitha Raavi, Data Engineer.

A static site (HTML, CSS, and vanilla JavaScript) with no build step required.

## Structure

```
index.html                     # All page content
assets/css/styles.css          # Styles
assets/js/main.js              # Mobile menu, active nav link, scroll animations
assets/img/about.jpg           # Profile photo
assets/Bavitha_Raavi_Resume.pdf
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Deploy (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)`.
